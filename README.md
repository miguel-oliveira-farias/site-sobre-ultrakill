Site falando sobre um jogo chamado ULTRAKILL

- Link do projeto publicado no Github Pages
https://miguel-oliveira-farias.github.io/site-sobre-ultrakill/

- Explicação da estrutura do projeto
O projeto possui quatro páginas, cada uma com um conteúdo diferente sobre o jogo ULTRAKILL. Comecei usando uma navbar para o usuário poder navegar entre as páginas, mais uma imagem para servir como títulos para elas, e coloquei essa estrutura em todas as páginas do site.
Na página prinicpal usei um carousel para mostrar algumas imagens do jogo para o usuário, mais um textinho mostrando uma breve introdução do jogo.
Na página Sobre, coloquei duas sections para fazer dois parágrafos com imagens ao lados e usei display flex para deixar alinhado, seguido de um texto com um link redirecionando para a página do jogo.
Na página História, usei um dropdown para o usuário poder se mover pela página mais facilmente, mais duas sections para mostrar todo o texto da página.
Na página Personagens, estruturei o site usando o sistema de layout do bootstrap para alinhar os cards para todos os dispositivos, deixando tudo organizado e no tamanho certo.

- Componentes Bootstrap utilizados
navbar, carousel, dropdown, card, modal

- Decisões de layout e design
O layout do bootstrap só foi necessário na página de personagens para deixar tudo alinhado e responsivo para todos os dispositivos, e na página Sobre para colocar o texto e a imagem lado a lado.

- Utilização do display flex
O display flex foi utilizado junto com o bootstrap para dar responsividade a página Sobre, deixando o texto e a imagem embaixo do outro em telas pequenas e usando flex-row para deixar-los lado a lado em telas maiores.
